About this tool:

This interface helps you generate VASP INCAR files by combining standard parameters, task-specific settings, and custom options.

Workflow:

  1. Select a calculation task or custom parameters
  2. Choose which standard parameter sections to include
  3. Add any custom parameters as needed
  4. Click "Generate INCAR" to preview
  5. Download or copy the generated INCAR file
